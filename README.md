# Predicting-Severe-Traffic-Crashes-in-Georgia-using-Machine-Learning

A machine learning project that predicts the probability of severe traffic accidents in Georgia using logistic regression, with historical analysis and two-year forward forecasting.

---

## Overview

This project uses the **US Accidents (Georgia subset)** dataset to build a binary classifier that distinguishes severe crashes (Severity 3–4) from non-severe ones (Severity 1–2). The trained model is then used to generate monthly predicted severe crash probabilities for the next two years, extending seasonal patterns observed in historical data.

---

## Features

- **Exploratory Data Analysis** — visualizes the distribution of crash severity (original 1–4 scale and binary target)
- **Logistic Regression Classifier** — trained on weather, temporal, and geographic features to predict crash severity
- **Feature Engineering** — frequency-encodes categorical columns (City, County, Weather Condition) and extracts time-based features (Month, Hour, DayOfWeek, IsNight)
- **Future Forecasting** — generates synthetic daily records for the next two years and predicts monthly severe crash risk
- **Historical vs. Future Comparison** — overlays historical predicted probabilities with future projections on a single time-series plot, with statistical summaries

---

## Dataset

**File:** `US_Accidents_GA_minimal.xlsx`

The dataset contains records of US traffic accidents filtered to Georgia. Key columns used:

| Column | Description |
|---|---|
| `Start_Time` | Timestamp of the accident |
| `Severity` | Original severity rating (1 = least, 4 = most severe) |
| `Severity_Binary` | Derived binary target: 0 = Non-Severe (1–2), 1 = Severe (3–4) |
| `Start_Lat` / `Start_Lng` | Geographic coordinates |
| `Temperature(F)` | Ambient temperature |
| `Humidity(%)` | Relative humidity |
| `Visibility(mi)` | Visibility distance |
| `Wind_Speed(mph)` | Wind speed |
| `Precipitation(in)` | Precipitation amount |
| `City_freq` | Frequency-encoded city |
| `County_freq` | Frequency-encoded county |
| `Weather_Condition_freq` | Frequency-encoded weather condition |

## Usage

Open and run the notebook cells in order:

```bash
jupyter notebook ML_Project_traffic__1_.ipynb
```

**Cell execution order:**

1. **Cell 1** — Load data, train the logistic regression model, scale features, and generate historical monthly predicted probabilities (`monthly_prob`)
2. **Cell 2** — Visualize severity distributions (original and binary)
3. **Cell 3** — Generate synthetic future data for the next two years and produce the combined historical + future forecast plot
4. **Cell 4** — Print a statistical comparison between historical and future predicted severe crash risk

> **Note:** Cells must be run in sequence. Cells 3 and 4 depend on the model (`log_reg`), scaler (`scaler`), feature column list (`feature_cols`), frequency maps, and `monthly_prob` produced in Cell 1.

## Model

**Algorithm:** Logistic Regression (`sklearn.linear_model.LogisticRegression`)

**Features (14 total):**

- Geographic: `Start_Lat`, `Start_Lng`
- Weather: `Temperature(F)`, `Humidity(%)`, `Visibility(mi)`, `Wind_Speed(mph)`, `Precipitation(in)`
- Temporal: `Month`, `Hour`, `DayOfWeek`, `IsNight`
- Frequency-encoded: `City_freq`, `County_freq`, `Weather_Condition_freq`

**Preprocessing:** All features are standardized using `StandardScaler` before training and inference.

**Evaluation:** The notebook outputs a `classification_report` and `confusion_matrix` on the held-out test set.

---

## Forecasting Methodology

Future predictions are generated by:

1. Taking the last recorded date in the dataset and projecting daily records forward for 730 days
2. Substituting monthly median values for continuous weather features (preserving seasonality)
3. Using the overall median for geographic and frequency-encoded features
4. Scaling the synthetic records with the pre-fitted `StandardScaler`
5. Predicting severe crash probability with the pre-trained logistic regression model
6. Resampling daily predictions to monthly averages for visualization
